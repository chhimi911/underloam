Underloam

Underloam is a local Python/Pygame desktop prototype. Vercel can host this project page, but the playable game opens a native Pygame window on your Mac.

Run locally

python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py

Controls

Move with arrows or A/D. Dash as Springtail with Left Shift or J. Jump as Dung Beetle with Space. Tunnel as Earthworm with Down plus left or right.
